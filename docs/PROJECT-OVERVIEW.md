# Project Overview

## Purpose

Pizza Delivery is a full-stack web application created for the OIBSIP Web Development & Designing Level 3 task.

## Main application areas

1. Customer authentication
2. Pizza customization
3. Order creation and tracking
4. Inventory management
5. Admin order management
6. Password-reset email flow
7. Scheduled low-stock notifications

## Technology

- React.js
- React Router
- Axios
- Node.js
- Express.js
- MongoDB / Mongoose
- JWT
- bcrypt
- Nodemailer
- node-cron

## Current repository state

The application source is currently stored in `OIBSIP-WebDev-L3-PizzaDelivery.zip`. The repository's `frontend/` and `backend/` folders currently provide documentation rather than duplicated source code.

For a stronger code-review experience, the next repository improvement is to extract the archive and commit the actual application source into a clean `frontend/` and `backend/` structure.
